# Claudinho Moto Preparações 🏍️

Site institucional desenvolvido para a oficina Claudinho Moto Preparações, com o objetivo de apresentar a empresa, serviços de preparação de motores e facilitar o contato com os clientes.

## 🚀 Tecnologias Utilizadas
* **HTML5:** Estrutura das páginas e SEO (Sitemap e Robots.txt).
* **CSS3:** Estilização e design responsivo.
* **JavaScript:** Interatividade da página (como o menu).
* **Hospedagem:** [Vercel](https://vercel.com/)

## 🔗 Acesso ao Site
O site já está no ar e pode ser acessado através do link:
[https://claudinhomotopreparacoes.vercel.app/](https://claudinhomotopreparacoes.vercel.app/)

## 🛠️ Como testar o projeto localmente
1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no seu computador.
3. Dê um duplo clique no arquivo `index.html` para abrir diretamente no navegador, ou utilize a extensão *Live Server* no Visual Studio Code.
